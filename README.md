# নামাজ (NAMAZ) — Android project

এই ZIP ফাইলটি এখনো APK নয়। এতে GitHub Actions-এর মাধ্যমে অনলাইনে APK বানানোর workflow যোগ করা হয়েছে।

## সহজ পদ্ধতি (কম্পিউটার বা মোবাইল ব্রাউজার থেকে)
1. https://github.com খুলে একটি অ্যাকাউন্ট তৈরি/সাইন ইন করুন।
2. **New repository** চাপুন, নাম দিন `NamazAndroid`, Public নির্বাচন করে **Create repository** চাপুন।
3. **Add file → Upload files** চাপুন। এই ZIP-টি আগে Extract/Unzip করে ভেতরের ফাইল-ফোল্ডারগুলো আপলোড করুন (ZIP-টিকে একটিমাত্র ফাইল হিসেবে নয়)। **Commit changes** চাপুন।
4. Repository-তে **Actions** ট্যাব খুলুন. `Build Namaz APK` নির্বাচন করে **Run workflow** চাপুন (অথবা main-এ আপলোডের পর নিজে থেকেই শুরু হতে পারে)।
5. কাজ শেষ হলে সবুজ ✔ দেখাবে। সেই run খুলে নিচের **Artifacts** অংশে `Namaz-APK` চাপুন। ডাউনলোড হওয়া ZIP খুললে `app-debug.apk` পাবেন। সেটিই Android ফোনে ইনস্টল করবেন।

## অ্যাপ সম্পর্কে
- AlAdhan API থেকে দৈনিক নামাজের সময় আনে।
- অ্যাপটি পাঁচ ওয়াক্তের অ্যালার্ম/নোটিফিকেশন সেট করার প্রাথমিক ব্যবস্থা রাখে।
- পূর্ণ আজানের অডিও ফাইল এই প্রজেক্টে অন্তর্ভুক্ত নয়। ফলে এটি এখনো সম্পূর্ণ আজান-অডিও-সহ চূড়ান্ত অ্যাপ নয়।
- APK তৈরি হলেও বাস্তব ফোনে পরীক্ষা না করা পর্যন্ত অ্যালার্ম সব ফোনে নির্ভরযোগ্যভাবে বাজবে—এ নিশ্চয়তা দেওয়া যায় না।
